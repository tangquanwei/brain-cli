# Markdown 与公式

这篇笔记用于演示白板卡片的 Markdown 预览和公式支持。

## 常用语法

- **粗体**与*斜体*
- `inline code`
- [本地优先原则](<./本地优先原则.md>)

行内公式可以写成 `$E = mc^2$`，也可以写 `$a_1 + a_2 = a_3$`。

## 块级公式

$$
\frac{1}{n} \sum_{i=1}^{n} x_i = \bar{x}
$$

公式支持常见的希腊字母，例如 `$\alpha + \beta = \gamma$`，以及上下标和分数。
