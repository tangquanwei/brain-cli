自由记录，

编辑器帮助你创造内容。随着文件、链接和附件不断增加，2ndBrain CLI 负责那些容易出错、又不断重复的维护工作。

01安全重构

重命名，不破坏上下文

移动或重命名笔记时，同步更新相对 Markdown 链接、已解析 WikiLink 和对应图片目录。先用 --dry-run 预览每一项变化。

02只读检查

在问题扩散前发现它

检查断链、缺失标题和块引用、丢失附件、歧义 WikiLink、反向链接和孤岛笔记。

03限定 GIT 范围

保留可恢复的历史

只提交配置的笔记仓库，并可选择推送远端；周围的工作区不会被纳入操作范围。

04本地 WEBUI

看到系统，而不只是一堆文件

在只监听本机的控制台中浏览笔记、链接健康、回顾、反向链接和知识图谱。

直接连接现有知识库

三步，从文件夹走向清晰。

没有导入流程，也没有专有数据库。将 2ndBrain CLI 指向普通 Markdown 文件，从一次只读体检开始。

第 01 步

体检

无需初始化或移动文件，直接对任意 Markdown 或 Obsidian 知识库执行只读诊断。

brain doctor /path/to/notes
第 02 步

理解

打开本地仪表盘，在上下文中探索笔记、健康信号、回顾和内容关系。

brain --vault /path/to/notes web --open
第 03 步

维护

先预览再重构，随手捕获新想法，并把结果保存在限定范围的 Git 历史中。

brain rename old new --dry-run

一个本地控制台

让知识库真正可见。

WebUI 将同一批本地 Markdown 转化为可操作的视图。阅读和编辑笔记、追踪链接、完成回顾、探索图谱，全程无需把内容发送到托管服务。

  • 仪表盘与最近笔记
  • 链接健康诊断
  • 交互式知识图谱

安全本身就是产品能力

边界清晰，意外无聊。

一个会修改知识库的工具，应该明确告诉你它的边界。只读检查、dry-run 重构、本地网络和限定知识库范围的 Git 行为都被设计进了工作流。

阅读安全策略 →
⌂仅限本地网络WebUI 默认只监听 127.0.0.1，不暴露到公网。
◉检查默认只读Doctor、链接扫描、反向链接、状态、回顾和 dry run 都不会修改文件。
⑂Git 范围明确备份和 Watcher 只操作配置的笔记仓库。
↺重构前先预览大规模重命名或移动前，先使用 --dry-run 并保留 Git 历史。

小命令，明确意图

专注于日常维护的工具箱。

一次使用一个命令，或者让 Watcher 在后台进行轻量维护。

brain doctor检查现有知识库

不写入文件，检查目录结构和配置。

brain links审计链接健康

发现断链、孤岛、丢失附件和歧义 WikiLink。

brain backlinks追踪引用上下文

查看哪些笔记链接到了当前内容。

brain rename / move安全重构

更新笔记以及依赖它的链接，并支持 dry-run 预览。

brain backup保留历史

提交配置的笔记仓库，并可选择推送。

brain web打开可视化层

启动本地仪表盘、编辑器、体检、回顾和图谱。

为你的笔记加上维护层。
