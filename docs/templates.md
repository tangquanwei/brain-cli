# 📝 笔记模板说明

在 VS Code 中输入以下前缀可快速生成对应模板：

## 可用模板

| 前缀 | 说明 | 快捷键 |
|------|------|--------|
| `newnote` | 通用笔记模板 | 输入后按 Tab |
| `daily` | 每日笔记模板 | 输入后按 Tab |
| `weekly` | 每周回顾模板 | 输入后按 Tab |

## 使用方法

1. 在 `notes/` 目录下新建 `.md` 文件
2. 输入模板前缀（如 `daily`）
3. 按 `Tab` 键展开模板
4. 使用 `Tab` 在各占位符之间跳转填写

## PARA 分类

将笔记保存到对应目录：

- `notes/projects/` — 正在进行的项目
- `notes/areas/` — 长期维护的领域
- `notes/resources/` — 主题资源收藏
- `notes/archives/` — 已归档内容
