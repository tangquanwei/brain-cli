# 图片管理方案（方案 A：图片与笔记同目录）

本仓库采用 **图片与 Markdown 笔记同目录** 的布局，移动 / 归档笔记时图片"一并搬走"，无需重写路径。

## 1. 目录布局

每篇笔记旁边放一个**同名文件夹**存放图片：

```
notes/areas/计算机AI/
├─ ppo.md
└─ ppo/
   ├─ ppo-2026-05-29-15-10-48.png
   └─ ppo-2026-05-29-15-12-03.png

notes/archives/2026/
├─ 2026-05-29.md
└─ 2026-05-29/
   └─ ...
```

笔记内部使用**相对路径**引用：

```markdown
![](ppo/ppo-2026-05-29-15-10-48.png)
```

> 同名文件夹与 Hexo `post_asset_folder: true` 的目录约定完全一致，知识库与博客图片路径规范统一。

## 2. VS Code 配置

已写入 [.vscode/settings.json](../.vscode/settings.json)：

```json
{
  "markdown.editor.filePaste.copyIntoWorkspace": "mediaFiles",
  "markdown.editor.drop.copyIntoWorkspace": "mediaFiles",
  "markdown.copyFiles.destination": {
    "**/*.md": "${documentDirName}/${documentBaseName}/${fileName}"
  },
  "markdown.copyFiles.overwriteBehavior": "nameIncrementally",
  "markdown.updateLinksOnFileMove.enabled": "always",
  "markdown.updateLinksOnFileMove.include": [
    "**/*.{md,png,jpg,jpeg,gif,svg,webp}"
  ],
  "markdown.updateLinksOnFileMove.enableForDirectories": true
}
```

### 可用变量

| 变量 | 含义 |
|---|---|
| `${documentWorkspaceFolder}` | 仓库根目录 |
| `${documentDirName}` | 当前 md 所在目录 |
| `${documentBaseName}` | 当前 md 文件名（不含 `.md`） |
| `${documentFileName}` | 当前 md 文件名 |
| `${fileName}` | 粘贴的文件原名 |
| `${fileExtName}` | 扩展名 |

## 3. 日常操作

### 3.1 插入图片
- **截图后** `Ctrl+V`：自动保存到 `<笔记名>/` 并插入引用。
- **拖拽** 文件到编辑区：同上。
- **预览**：`Ctrl+Shift+V`。

### 3.2 移动 / 归档笔记
将一篇笔记从 `notes/areas/` 移动到 `notes/archives/`：

1. 在资源管理器里选中 **`ppo.md` 和 `ppo/` 两项**；
2. 一起拖到目标目录（或 `Ctrl+X` → `Ctrl+V`）；
3. VS Code 会弹窗询问是否更新引用，选 **"Yes"**；
4. 完成 —— 引用是相对路径，目录改了也不会断。

> 关键：**别忘了同时选中同名图片文件夹**。

### 3.3 删除笔记
直接删 `xxx.md` 和 `xxx/` 两项即可，不会留下孤儿图片。

### 3.4 重命名笔记
重命名 `ppo.md` → `ppo-v2.md`，VS Code 会问是否更新引用，但 **`ppo/` 文件夹不会自动改名**。手动把文件夹也改成 `ppo-v2/` 后，再次确认更新引用即可。

## 4. 历史数据迁移

旧布局是集中式 `notes/images/<日期>/...`，对应 md 用 `images/2025-06-05/xxx.png` 这样的路径引用。

历史数据已通过 `scripts/migrate-images.mjs` 一次性完成迁移：

- 原集中式 `notes/images/<日期>/xxx.png` → 对应笔记的 `<name>/xxx.png`
- 原 `<name>.assets/` 目录 → 去掉 `.assets` 后缀改为 `<name>/`
- 所有 md 引用路径同步改写
- `notes/images/` 下残留 15 张未被引用的孤儿图片（可手动删除）

如需重新迁移，运行：

```bash
node scripts/migrate-images.mjs            # 先 dry-run 预览
node scripts/migrate-images.mjs --apply    # 确认后执行
```

## 5. 提交策略

- 图片直接进 Git（仓库现状）。
- 大截图先压缩（**TinyPNG** 插件 / `imagemin`），避免膨胀。
- 单文件 > 1 MB 的视频/录屏，考虑放图床或 Git LFS。

## 6. 与 `brain status` 的配合

`brain status` 递归统计 `.md` 时会跳过图片文件夹（图片不是 md），不影响统计准确性。

---

**TL;DR**：粘图自动落到 `<笔记名>/`，归档时连同同名文件夹一起拖走，相对路径永远不会断；目录规范与 Hexo `post_asset_folder` 统一。
