# 本地白板：Excalidraw + Markdown

运行 `npm run build`，然后运行 `node dist/cli.js web --open`，从侧栏打开白板。
已运行的服务需要重启，以加载新的场景保存接口。

- 使用 Excalidraw 原生工具绘图、连线、插入图片、缩放和撤销。
- 点击「笔记引用」搜索本地笔记，点击结果将标题和路径加入画布。
- 选择引用后，右侧显示对应 Markdown 的当前正文；点击「在 VS Code 编辑」打开原文件。
- VS Code 保存后，侧栏通过文件监听刷新。画布文字是可以自由修改的标注，不会写回笔记。
- 「导出白板」下载包含图片的 `.excalidraw` 文件，原生菜单支持重新导入及图片导出。

## 保存与迁移

场景保存在 `<notesDir>/.brain/whiteboards/<id>.excalidraw`，笔记正文仍保存在原 `.md` 文件。
画布使用 400ms 防抖自动保存，顶部显示保存状态。图片内嵌在场景文件中，单次保存请求上限为 32 MiB。

旧版 `<id>.json` 首次打开后转换为 Excalidraw 场景，原 JSON 保留作为备份。
卡片文字、笔记引用、位置和连线会迁移；折叠卡片展开显示全文，旧数据额外保留在元素 metadata 中。
新旧同名文件同时存在时，优先打开 `.excalidraw`。删除白板会删除这两份文件，不删除引用的 Markdown。

保存使用文件内容版本检查：其他窗口修改白板后，旧版本不能覆盖新版本。
发生冲突时，先「导出白板」保留当前内容，再「重新加载」；不会自动合并多个窗口的编辑。

## 本地使用边界

- `code` 命令必须在服务进程的 PATH 中；VS Code 可通过命令面板安装该命令。
- 笔记引用使用 vault 相对路径。外部移动或重命名 `.md` 后，需要重新添加引用；缺失引用会显示提示。
- 不提供画布内 Markdown 编辑或在线协作。字体、脚本与样式随构建打包，由本地服务提供。
- 侧栏渲染 Markdown 并清理 HTML；暂不提供本地 Markdown 附件图片的专用服务。
