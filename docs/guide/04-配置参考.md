# ⚙️ 配置参考

临时连接已有知识库时，优先使用全局 `--vault <path>`；需要持久默认值时，再使用工作区根目录的 `.env`。

```bash
copy .env.example .env    # Windows
cp .env.example .env      # macOS/Linux
```

---

配置优先级：

1. `brain --vault <path> <command>`
2. 进程环境或 `.env` 中的 `NOTES_DIR`
3. 当前工作区下的 `notes`

`--vault` 不修改 `.env`，也不会自动初始化目标目录。

## 配置项一览

### 本地存储

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `NOTES_DIR` | — | `notes` | 本地知识库目录，可使用工作区相对路径或绝对路径 |

默认生成的目录结构如下：

```
{NOTES_DIR}/
├── projects/    # 项目笔记
├── areas/       # 领域笔记
├── resources/   # 资源笔记（闪念、文献）
├── questions/   # 待研究问题
└── archives/    # 归档笔记
```

已有 Markdown/Obsidian 知识库不要求采用这套目录结构；可以直接执行 `brain doctor <path>` 或使用 `--vault`。只有 `brain init` 会创建默认目录。

---

### Git 自动备份设置

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `GIT_AUTO_COMMIT` | — | `true` | Watcher 运行时，是否允许自动提交变更 |

> **注意**：手动执行 `brain backup` 命令时不受此开关影响，必定会尝试提交。Git 操作只针对 `NOTES_DIR` 或 `--vault` 指向的知识库仓库。

---

### Watcher 守护进程行为

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `WATCH_ENABLED` | — | `true` | 是否启用 Watcher（监控 `notes/` 中的变化并触发备份） |
| `COMMIT_INTERVAL` | — | `30` | 发现修改后执行 `git commit` 的频率检查间隔（秒） |
| `PUSH_INTERVAL` | — | `900` | 自动推送 `git push` 的频率（秒，`0` 表示完全不自动推送） |

#### 常见配置方案

**高频同步（防丢失保护）**：

```dotenv
COMMIT_INTERVAL=15
PUSH_INTERVAL=300
```

**省流模式（主要在本地编辑，偶尔才推送备份）**：

```dotenv
COMMIT_INTERVAL=60
PUSH_INTERVAL=3600
```
