# ⚙️ 配置参考

所有配置通过仓库根目录下的 `.env` 文件进行管理。请手动创建，或通过 `.env.example` 复制。

```bash
copy .env.example .env    # Windows
cp .env.example .env      # macOS/Linux
```

---

## 配置项一览

### 本地存储

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `NOTES_DIR` | — | `notes` | 本地笔记存储目录（相对于项目根目录）；当前为 Git 子模块 |

默认生成的目录结构如下：

```
{NOTES_DIR}/
├── projects/    # 项目笔记
├── areas/       # 领域笔记
├── resources/   # 资源笔记（闪念、文献）
└── archives/    # 归档笔记
```

`notes/` 和 `blog/` 需要先通过 `git submodule update --init --recursive` checkout。notes 远程仓库是 `https://github.com/<your-account>/notes.git`，blog 远程仓库是 `https://github.com/<your-account>/blog.git`；Brain 总控仓库只记录两个子模块的 commit 指针，Butterfly 继续由 `blog/` 内部的嵌套子模块管理。

---

### Git 自动备份设置

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `GIT_AUTO_COMMIT` | — | `true` | Watcher 运行时，是否允许自动提交变更 |

> **注意**：手动执行 `brain backup` 命令时不受此开关影响，必定会尝试提交。当前实现只提交 `notes/` 仓库，不会提交 Brain 总控仓库、blog 或子模块指针。

---

### Watcher 守护进程行为

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `WATCH_ENABLED` | — | `true` | 是否启用 Watcher（监控 `notes/` 中的变化并触发备份） |
| `COMMIT_INTERVAL` | — | `30` | 发现修改后执行 `git commit` 的频率检查间隔（秒） |
| `PUSH_INTERVAL` | — | `900` | 自动推送 `git push` 的频率（秒，`0` 表示完全不自动推送） |

#### 常见配置方案

**高频同步（防丢失保护）**：

```dotenv
COMMIT_INTERVAL=15
PUSH_INTERVAL=300
```

**省流模式（主要在本地编辑，偶尔才推送备份）**：

```dotenv
COMMIT_INTERVAL=60
PUSH_INTERVAL=3600
```
