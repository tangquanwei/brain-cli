# 🚀 快速开始

2ndBrain CLI 可以直接检查已有 Markdown/Obsidian 知识库，不需要先初始化、迁移文件或创建数据库。

## 安装

需要 Node.js 20 或更高版本。

```bash
npm install -g @qwtang/brain-cli
brain --version
```

## 先体检已有知识库

`doctor` 始终只读。它会检查目录可读性、Markdown 与 WikiLink、标题和块引用、嵌入图片或附件、歧义链接和孤岛笔记。

```bash
brain doctor /absolute/path/to/your/vault
```

有断链、缺失引用、缺失附件或歧义 WikiLink 时，命令返回退出码 1；不会创建目录、迁移笔记或写入 `.brain`。

需要 JSON：

```bash
brain doctor /absolute/path/to/your/vault --json
```

## 在已有知识库上运行其他命令

全局 `--vault <path>` 必须放在子命令前：

```bash
brain --vault /absolute/path/to/your/vault links --stats --orphans
brain --vault /absolute/path/to/your/vault backlinks "My Note"
brain --vault /absolute/path/to/your/vault web --open
```

`--vault` 只影响本次执行。需要持久配置时，在工作区创建 `.env`：

```dotenv
NOTES_DIR=/absolute/path/to/your/vault
```

路径优先级：

1. 命令行 `--vault <path>`
2. `.env` 或进程环境中的 `NOTES_DIR`
3. 当前工作区下的 `notes`

## 从 Notion 同步页面

`brain download` 使用 Notion 官方 API 读取页面，因此需要一个 Notion integration token。首次配置只需做一次：

1. 在 Notion 的 [My integrations](https://www.notion.so/profile/integrations) 创建 integration，复制 Internal Integration Secret。
2. 打开要同步的页面，点击右上角 `•••` → `Connections`，把该 integration 添加到页面。父页面未授权时，子页面也无法读取。
3. 在知识库 `.env` 中配置 token：

   ```dotenv
   NOTION_TOKEN=secret_xxx
   ```

   也可以只对当前命令临时传入：

   ```bash
   brain download "https://app.notion.com/p/qwtang/TLDR-3b178eafd44e8025b0b1cd05d4fb4581" --token "secret_xxx"
   ```

同步页面：

```bash
brain --vault /absolute/path/to/your/vault download \
  "https://app.notion.com/p/qwtang/TLDR-3b178eafd44e8025b0b1cd05d4fb4581"
```

默认结果为：

```text
<vault>/resources/<页面标题>.md
<vault>/resources/<页面标题>.assets/   # 页面中的图片和文件
```

页面 ID 会写入 frontmatter。再次执行同一个 URL 时，即使页面标题改了，也会更新原来的本地文件；如果同标题文件不是该页面，命令会停止而不会覆盖。页面正文中的段落、标题、列表、待办、引用、代码、链接和常见媒体块会转换为 Markdown。数据库、评论和页面历史不在当前同步范围内。

Token 只从环境变量或命令行读取，不会写入 Markdown；命令失败时也不会替换已有笔记。

## 创建新的知识库

```bash
mkdir my-brain
cd my-brain
brain init
brain web --open
```

`brain init` 会创建：

- `notes/projects/`
- `notes/areas/`
- `notes/resources/`
- `notes/questions/`
- `notes/archives/`
- 工作区的 `templates/`

## 第一次重构

重命名或移动前先使用只读预览：

```bash
brain --vault /path/to/vault rename "areas/Old.md" "New" --dry-run
brain --vault /path/to/vault move "areas/Old.md" "resources/New.md" --dry-run
```

确认文件、附件和链接更新范围后，去掉 `--dry-run` 才会实际写入。大规模操作前建议保留 Git 提交。

完整边界见 [CLI 命令参考](02-CLI命令参考.md)。
