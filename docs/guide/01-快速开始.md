# 🚀 快速开始

从零搭建你的第二大脑（基于 TypeScript CLI 版本）。

## 前置要求

| 工具 | 版本 | 用途 |
|------|------|------|
| Node.js | ≥ 20.0 | 运行环境 |
| npm/pnpm | 最新版 | 包管理器 |
| Git | 任意版本 | 本地版本控制 & 备份 |
| VS Code | 最新版 | 编辑器 |

## 第一步：安装依赖

如果是首次克隆 Brain 总控仓库，先拉取子模块：

```bash
git clone --recurse-submodules git@github.com:<your-account>/2ndBrain.git
```

如果已经在本地：

```bash
git submodule update --init --recursive
```

`notes/` 是独立 Git 子模块，远程为 `https://github.com/<your-account>/notes.git`；`blog/` 是独立 Hexo 子模块，远程为 `https://github.com/<your-account>/blog.git`。两者默认分支均为 `main`，博客内的 Butterfly 主题还会通过 blog 的递归子模块初始化。

```bash
cd brain-cli

# 安装所有依赖
npm install

# 构建项目到 dist/
npm run build

# 可选：将 brain 链接到全局环境变量，方便直接使用 `brain` 命令
npm link
```

博客依赖单独安装：

```bash
npm --prefix blog install
npm --prefix blog run build
```

## 第二步：配置环境变量

在项目根目录复制环境变量模板：

```bash
cp .env.example .env
```
（如果是 Windows，在项目根目录创建 `.env` 文件）

编辑 `.env` 文件，填入：

```dotenv
NOTES_DIR=notes
GIT_AUTO_COMMIT=true
COMMIT_INTERVAL=30
PUSH_INTERVAL=900
WATCH_ENABLED=true
```

## 第三步：初始化目录

```bash
# 全局链接过可以使用 brain init
brain init
```

`brain init` 会检查 / 创建默认的 PARA 目录结构：
- `notes/projects/`
- `notes/areas/`
- `notes/resources/`
- `notes/archives/`

请先完成子模块 checkout 再运行 `brain init`，避免把 `notes/` 当作总控仓库里的普通目录创建。

初始化完成后，即可通过 `brain help` 开始使用。
