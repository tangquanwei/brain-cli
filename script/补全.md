# brain 命令自动补全

支持 Bash、Zsh、PowerShell（pwsh）。推荐直接运行安装脚本，按提示自动配置：

- macOS / Linux：`brain-cli/script/install.sh`
- Windows：`brain-cli/script/install.ps1`

## 手动配置

### Bash / Zsh（macOS / Linux）

在 `~/.bashrc` 或 `~/.zshrc` 中追加一行（把 `<仓库根目录>` 替换为实际路径）：

```bash
source "<仓库根目录>/brain-cli/script/brain-completion.sh"
```

然后重开终端，或执行 `source ~/.bashrc` / `source ~/.zshrc`。

### PowerShell / pwsh（Windows / macOS / Linux）

1. 查看 profile 路径：

   ```powershell
   $PROFILE
   ```

2. 不存在则创建：

   ```powershell
   if (!(Test-Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
   ```

3. 追加加载行（把 `<仓库根目录>` 替换为实际路径）：

   ```powershell
   Add-Content $PROFILE "`n. '<仓库根目录>/brain-cli/script/brain-completion.ps1'"
   ```

4. 重开终端，或执行 `. $PROFILE` 使其生效。

## 临时使用（不写入配置）

```bash
# Bash / Zsh，在仓库根目录下
source brain-cli/script/brain-completion.sh
```

```powershell
# PowerShell，在仓库根目录下
. ./brain-cli/script/brain-completion.ps1
```

## 补全内容

覆盖全部命令与子命令：`init`、`status`、`capture`/`new`、`backup`、`watch`（start/stop/status）、`review`（week/month/tags/random）、`rename`、`move`、`links`、`backlinks`、`web`，以及常用选项和 `--scope`、`--type` 的候选值。

## 附：Windows PowerShell 5.1 迁移到 PowerShell 7

新版补全脚本在 5.1 和 7 都能用，但建议升级到 PowerShell 7：

```powershell
winget install --id Microsoft.PowerShell --source winget
$PSVersionTable.PSVersion   # 查看版本
```

迁移旧 profile：

```powershell
$src = "$HOME\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1"
$dst = "$HOME\Documents\PowerShell\Microsoft.PowerShell_profile.ps1"
New-Item -ItemType Directory -Force -Path (Split-Path $dst) | Out-Null
Copy-Item $src $dst
```
